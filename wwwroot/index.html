    Reassess Saved History

    Queue every saved story for review using your current interests and model. Previous summaries stay visible until replaced. Bookmarks and dates are preserved. This can take time on a small computer.

    Purge Duplicates

    This permanently deletes AI-marked duplicate stories that are not bookmarked or referenced by other stories. Main stories, bookmarks, interests, sources, and collection settings are kept.

    The database is compacted afterward to reclaim space. This can take time. Deleted articles may be collected again if they are still listed by a source. Export a backup first if you may want them back.

    Fresh Start

    Only the selected items will be cleared, then the database is compacted to free disk space. This cannot be undone in NewsReview. Use File > Import/Export... to download a backup first if you might want to restore them.

    Choose what to clear

    Clearing story or run history restarts the automatic collection interval. Manual Check Sources remains available. Your password and saved model keys are kept.

    Article Feedback

    Reset Feedback

    Remove all article ratings, reasons, and the learned preference profile. Written interests, guidance, bookmarks, and stories are kept.

    About NewsReview

    A self-hosted news reader. It collects stories from the feeds and websites you add under Settings > Sources, and your configured AI model filters, scores, summarizes, and tags them by your interests and editorial guidance.

    Tips: add a homepage, news section, category page, or feed that lists many articles, not a single article, and use Preview stories before saving. Without a model, stories are still collected; Review Pending runs the AI stage later. File > Import/Export... backs up everything except your password and saved model keys.     Restore a Backup Before Starting

    If you have a NewsReview backup ZIP, restore it before adding sources. Use File > Import/Export... to restore it. Restoring a backup replaces all current data, so anything you set up first would be replaced by a later restore. If you don't have a backup, choose Start Fresh.

    Import/Export

    Download Backup saves a ZIP with stories, bookmarks, sources, interests, guidance, AI/collection settings, feedback, and run history, including committed changes while the app runs. It contains the SQLite database and a backup manifest, but never your password or saved model keys.

    Restore a NewsReview backup ZIP to replace all current data after confirmation. It does not merge. The current data is saved on the server in data/backups first. Maximum ZIP size: 256 MiB; maximum database size: 1 GiB.
