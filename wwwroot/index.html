Help - NewsReview

What AI reviews do

Your configured model checks each story against your interests, editorial guidance, and exclusions. It scores relevance, summarizes what happened, selects tags from Settings → Topics, identifies milestones such as proposals versus shipped features, and checks likely duplicate coverage. Add, rename, or delete topics there; AI cannot invent new ones.

NewsReview tries to summarize the extracted article text. If the article page cannot be read reliably, it falls back to the source's RSS/Atom excerpt and marks that tile AI summary · based on source excerpt. Full-article summaries are left unlabeled to keep the feed uncluttered.

Filtered stories remain in the database but are hidden in the normal feed. Open Filter... and select Include filtered / duplicates to inspect them. Bookmarked stories remain visible if later filtered. Without a configured model, collection still saves headlines and available excerpts; Review pending runs the AI stage later.

Article feedback

Use thumbs up/down on a tile and optionally explain why. Ratings and reasons stay saved; a compact preference profile is refreshed once before a review batch when needed. Edit, disable, update, or reset it in Settings, Interests. Written interests and guidance take priority. All stories show a summary without a separate Why it matters section.

Adding sources

Open Settings, Sources, then Add source. Use a homepage, news section, or category page that lists multiple articles, rather than a single article URL. Enter a name and category, choose a collection method, and use Preview stories before saving.

Automatic prefers a supplied or advertised RSS/Atom feed. If it fails, is empty, or becomes stale according to the source warning interval, it also checks the website listing. Website results are merged with usable feed entries; if the website cannot be read, feed entries are kept and the limitation is shown. RSS/Atom only reports feed failures. Website page reads article cards, headline links, and structured lists directly from downloaded HTML. An optional Article URL contains filter, such as /news/, narrows website candidates.

Forums and threads

Choose a relevant subforum/category page or its feed that lists threads. NewsReview opens the linked threads as story candidates, then your model filters the discussions. A single thread is one discussion, not a continuing list of new stories; new replies do not automatically create new tiles for the same thread URL. Forum discussions are not necessarily verified reporting.

What gets downloaded

Feeds/listings find the links. During AI review, NewsReview downloads each article or thread page to extract readable text. A headline-only feed can work if that page is readable. If it is blocked, only the available excerpt is used and labeled. JavaScript-only, restricted, or unusual pages may need a custom adapter.

Search and source health

Combine dates and times with a comma: 9/1/26 - 10/1/26, 10am - 3pm. A date range or time range alone also works. Times match the displayed publication time in your browser timezone, or collection time for undated stories; overnight ranges are supported. Topics match any checked selection.

Sort orders Daily Feed and Bookmarks by publication time (newest or oldest first) or relevance rank (highest or lowest first). Rank uses the saved AI score. The choice applies before pagination and is remembered in this browser; changing it does not run AI again.

Check new sources collects only enabled sources that have never been checked, including newly added sources. Refresh sources checks all enabled sources, including failed ones. The Sources tab warns about failed checks, repeated failures, stale checks, and possible inactivity. Change each source's warning interval for slower publishers. The yellow/orange indicator means collection or review is running.

Backups and fresh starts

Open Settings, Collection & history, then Import/Export to download a complete ZIP containing stories, bookmarks, sources, preferences, and run history. Restoring replaces the current dataset after validation and saves a recovery ZIP on the server first. Login credentials and the browser theme are kept.

Fresh start in Settings lets you clear selected data, including history, bookmarks, interests, guidance, sources, or settings. Unchecked categories are preserved. Keeping Bookmarks unchecked preserves saved stories when clearing other history.

Import/Export

Download a complete NewsReview ZIP with stories, bookmarks, sources, interests, guidance, AI/collection settings, and run history. It includes committed database changes while the app runs. Store it privately; the ZIP is not encrypted.

Choose a NewsReview export ZIP. Restoring replaces the current dataset rather than merging it. The server validates it and saves a private recovery ZIP before changing anything. Your login password and browser theme are not replaced.

Maximum ZIP size: 256 MiB. Maximum database size: 1 GiB.
